# generate_venn_chart — диаграмма Венна

## Назначение
Показывает пересечения, объединения и различия нескольких множеств. Подходит для сегментации рынка, покрытия функциональности, анализа перекрытия аудиторий.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `value` (number) и `sets` (string[]), опционально `label` (string).

### Опциональные
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], список цветов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Число множеств желательно ≤4. При отсутствии точных весов допустимо указать приблизительные доли. Названия множеств делайте краткими и однозначными (например, «Мобильные пользователи»).

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
