# generate_path_map — карта маршрутов (Китай)

## Назначение
Показывает маршрут или поездку по территории Китая на основе карт Amap, последовательно соединяя набор POI; подходит для логистических маршрутов, планирования путешествий, треков доставки.

## Входные поля
### Обязательные
- `title`: string, обязательное, не длиннее 16 символов, описывает тему маршрута.
- `data`: array<object>, минимум 1 объект маршрута.
- `data[].data`: string[], обязательное, содержит названия POI на территории Китая в порядке следования по маршруту.

### Опциональные
- `width`: number, по умолчанию `1600`.
- `height`: number, по умолчанию `1000`.

## Рекомендации
Названия POI должны быть конкретными и находиться в Китае (например, «Колокольная башня в Сиане», «Дамба Су на озере Сиху в Ханчжоу»); для нескольких маршрутов добавьте несколько объектов в `data`.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
