# generate_area_chart — диаграмма с областями

## Назначение
Показывает динамику значений по непрерывной независимой переменной (обычно по времени); при включённом наложении областей видно накопленный вклад отдельных групп. Подходит для KPI, энергопотребления, объёмов выпуска и других временных рядов.

## Входные поля
### Обязательные
- `data`: массив, элементы содержат `time` (string) и `value` (number); для наложения нужно дополнительно указать `group` (string). Минимум 1 запись.

### Опциональные
- `stack`: boolean, по умолчанию `false`; при включении каждая запись данных обязана содержать поле `group`.
- `style.backgroundColor`: string, задаёт цвет фона диаграммы (например, `#fff`).
- `style.lineWidth`: number, задаёт толщину линии границы области.
- `style.palette`: string[], массив-палитра для раскраски серий.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough` — управляет эффектом рисунка от руки.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`, задаёт ширину диаграммы.
- `height`: number, по умолчанию `400`, задаёт высоту диаграммы.
- `title`: string, по умолчанию пустая строка, задаёт заголовок диаграммы.
- `axisXTitle`: string, по умолчанию пустая строка, задаёт заголовок оси X.
- `axisYTitle`: string, по умолчанию пустая строка, задаёт заголовок оси Y.

## Рекомендации
Следите за единообразием формата поля `time` (например, `YYYY-MM`); в режиме наложения все группы должны покрывать одни и те же моменты времени — пропуски лучше заполнить заранее.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
