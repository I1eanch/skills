# generate_line_chart — линейный график

## Назначение
Показывает тренд по времени или другой непрерывной переменной, поддерживает сравнение нескольких серий; подходит для мониторинга KPI, прогнозов метрик и анализа динамики.

## Входные поля
### Обязательные
- `data`: array<object>, каждый элемент содержит `time` (string) и `value` (number); при нескольких сериях добавляется `group` (string).

### Опциональные
- `style.lineWidth`: number, толщина линии.
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], цвета серий.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.
- `axisYTitle`: string, по умолчанию пустая строка.

## Рекомендации
Точки времени всех серий должны быть выровнены; форматируйте их по ISO, например `2025-01-01` или `2025-W01`; данные высокой частоты лучше заранее агрегировать до дневной или недельной гранулярности, чтобы график не был перегружен.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
