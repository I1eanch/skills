# generate_word_cloud_chart — облако слов

## Назначение
Регулирует размер и расположение слов по частоте или весу. Используется для быстрого выделения тем текста, тональности и ключевых слов.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `text` (string) и `value` (number).

### Опциональные
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], цвета облака слов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Перед построением удалите стоп-слова и объедините синонимы. Приведите регистр к единому виду, чтобы избежать дублей. Для акцента на тональности сопоставьте цвет с положительными и отрицательными значениями.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
