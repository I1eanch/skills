# generate_funnel_chart — воронка

## Назначение
Показывает поэтапную конверсию или отток, применяется для воронки продаж, пути пользователя и других процессов последовательного отбора.

## Входные поля
### Обязательные
- `data`: array<object>, элементы располагаются в порядке этапов процесса, каждый содержит `category` (string) и `value` (number).

### Опциональные
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], цвета этапов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Этапы должны идти в порядке реального процесса; если значения заданы в процентах, приведите их к единой базе и укажите методику в заголовке или примечании; избегайте слишком большого числа этапов — читаемость падает (рекомендуется ≤6).

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
