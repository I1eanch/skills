# generate_pie_chart — круговая диаграмма

## Назначение
Показывает соотношение целого и его частей; заданный внутренний радиус превращает диаграмму в кольцевую. Подходит для доли рынка, структуры бюджета, разбивки пользовательских сегментов.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `category` (string) и `value` (number).

### Опциональные
- `innerRadius`: number, диапазон [0, 1], по умолчанию `0`; значение вида `0.6` даёт кольцевую диаграмму.
- `style.backgroundColor`: string, задаёт цвет фона.
- `style.palette`: string[], список цветов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Категорий желательно не больше 6; лишние объединяйте в «Прочее». Следите за единством единиц измерения (проценты или абсолютные значения) и при необходимости указывайте базу расчёта в заголовке.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
