# generate_spreadsheet — таблица и сводная таблица

## Назначение
Строит таблицу или сводную таблицу для показа структурированных табличных данных. Если задано поле `rows` или `values`, результат рендерится как сводная (кросс-)таблица; иначе — как обычная таблица. Подходит для отображения структурированных данных, сравнения значений между категориями и построения сводок.

## Входные поля
### Обязательные
- `data`: array<object>, массив строк таблицы: каждый объект — одна строка. Ключи — имена столбцов, значения — строка, число, null или undefined. Например: `[{ name: 'John', age: 30 }, { name: 'Jane', age: 25 }]`.

### Опциональные
- `rows`: array<string>, поля заголовков строк сводной таблицы. Если задано `rows` или `values`, таблица рендерится как сводная.
- `columns`: array<string>, поля заголовков столбцов, задают порядок столбцов. Для обычной таблицы определяют порядок столбцов; для сводной — группировку по столбцам.
- `values`: array<string>, поля значений сводной таблицы. Если задано `rows` или `values`, таблица рендерится как сводная.
- `theme`: string, по умолчанию `default`, допустимо `default`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.

## Рекомендации
- Для обычной таблицы достаточно передать `data` и, при необходимости, `columns` для управления порядком столбцов.
- Для сводной (кросс-)таблицы передайте `rows` для группировки по строкам, `columns` — по столбцам, `values` — агрегируемые поля значений.
- Убедитесь, что имена полей в данных совпадают с именами, указанными в `rows`, `columns` и `values`.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
