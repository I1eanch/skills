# generate_dual_axes_chart — диаграмма с двумя осями

## Назначение
Совмещает на одном полотне столбцы и линию (или две кривые с разными единицами измерения), чтобы одновременно показать тренд и сравнение: выручка против прибыли, температура против осадков.

## Входные поля
### Обязательные
- `categories`: string[], значения шкалы оси X по порядку (годы, месяцы, категории).
- `series`: array<object>, каждый элемент содержит как минимум `type` (`column`/`line`) и `data` (number[], длина совпадает с `categories`); опционально `axisYTitle` (string) описывает смысл оси Y этого ряда.

### Опциональные
- `style.backgroundColor`: string, свой цвет фона.
- `style.palette`: string[], палитра для нескольких рядов.
- `style.texture`: string, по умолчанию `default`, доступно `default`/`rough`.
- `theme`: string, по умолчанию `default`, доступно `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.

## Рекомендации
Применяйте только когда действительно есть разные единицы измерения или нужно сопоставление по легенде. Держите число рядов ≤2, иначе диаграмма становится трудночитаемой. Если значения двух кривых различаются на порядки, используйте вторую ось для масштабирования.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
