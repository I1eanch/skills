# generate_district_map — картограмма по регионам

## Назначение
Строит заливку или тепловую карту по административным единицам (регион / город / район / округ), показывая диапазоны показателя, категории или состав территории. Подходит для региональных продаж, охвата программ и подобных задач.

## Входные поля
### Обязательные
- `title`: string, обязательное, не длиннее 16 символов, описывает тему карты.
- `data`: object, обязательное, содержит настройки административных единиц и данные показателя.
- `data.name`: string, обязательное, название административной единицы; уровень должен быть указан явно (регион / город / район / округ).

### Опциональные
- `data.style.fillColor`: string, свой цвет заливки для областей без данных.
- `data.colors`: string[], дискретная или непрерывная цветовая шкала; по умолчанию используется список из 10 цветов.
- `data.dataType`: string, одно из `number`/`enum`, задаёт способ сопоставления цвета.
- `data.dataLabel`: string, название показателя (например, `GDP`).
- `data.dataValue`: string, значение показателя или метка категории.
- `data.dataValueUnit`: string, единица измерения показателя (например, `млрд`).
- `data.showAllSubdistricts`: boolean, по умолчанию `false`, показывать ли все вложенные административные единицы.
- `data.subdistricts[]`: array<object>, для детализации по вложенным областям; каждый элемент содержит как минимум `name`, дополнительно — `dataValue` и `style.fillColor`.
- `width`: number, по умолчанию `1600`, ширина изображения.
- `height`: number, по умолчанию `1000`, высота изображения.

## Рекомендации
Название должно точно соответствовать административному уровню — избегайте расплывчатых формулировок. Если задан `subdistricts`, одновременно включайте `showAllSubdistricts`. Набор доступных границ ограничен геоданными используемого источника: проверяйте, что нужный регион в нём есть.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
