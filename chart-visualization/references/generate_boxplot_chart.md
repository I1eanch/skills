# generate_boxplot_chart — диаграмма «ящик с усами»

## Назначение
Показывает разброс данных по категориям (минимум и максимум, квартили, выбросы). Применяется для контроля качества, результатов экспериментов и сравнения распределений в группах.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `category` (string) и `value` (number); опционально `group` (string) для сравнения нескольких групп.

### Опциональные
- `style.backgroundColor`: string, задаёт цвет фона.
- `style.palette`: string[], список цветов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.
- `axisYTitle`: string, по умолчанию пустая строка.

## Рекомендации
На одну категорию давайте не менее 5 наблюдений, иначе статистика теряет смысл; несколько партий показывайте через `group` либо разбивайте на отдельные вызовы.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
