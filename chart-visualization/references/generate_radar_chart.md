# generate_radar_chart — лепестковая диаграмма

## Назначение
Сравнивает один или несколько объектов по набору измерений в многомерной системе координат. Применяется для оценок, сравнения продуктов, профилей результативности.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `name` (string) и `value` (number), опционально `group` (string).

### Опциональные
- `style.backgroundColor`: string, задаёт цвет фона.
- `style.lineWidth`: number, толщина линий диаграммы.
- `style.palette`: string[], цвета серий.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Держите число измерений в пределах 4–8; разные объекты разделяйте через `group` и задавайте значение по каждому измерению. При разных размерностях сначала выполните нормализацию.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
