# generate_network_graph — граф связей

## Назначение
Показывает связи между сущностями через узлы и соединяющие линии; подходит для социальных сетей, зависимостей систем, графов знаний и подобных сценариев.

## Входные поля
### Обязательные
- `data`: object, обязательное, содержит узлы и связи.
- `data.nodes`: array<object>, минимум 1 элемент, требуется уникальное `name`.
- `data.edges`: array<object>, минимум 1 элемент, содержит `source` и `target` (string), опционально `name` с описанием связи.

### Опциональные
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.

## Рекомендации
Держите количество узлов в диапазоне 10–50, чтобы избежать перегруженности; убедитесь, что `source`/`target` в `edges` ссылаются на существующие узлы; смысл связи можно пояснить в `label`.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
