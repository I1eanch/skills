# generate_organization_chart — организационная схема

## Назначение
Отображает иерархию компании, команды или проекта; в узлах можно описать роли и обязанности.

## Входные поля
### Обязательные
- `data`: object, обязательное; узел содержит минимум `name` (string), опционально `description` (string), дочерние узлы вкладываются через `children` (array<object>), рекомендуемая максимальная глубина — 3.

### Опциональные
- `orient`: string, по умолчанию `vertical`, допустимо `horizontal`/`vertical`.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.

## Рекомендации
В названиях узлов используйте должности или роли, в `description` кратко указывайте обязанности либо численность; для крупной организации разбейте схему на несколько подсхем или показывайте её по подразделениям.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
