# generate_liquid_chart — индикатор заполнения

## Назначение
Отображает одиночный процент или прогресс уровнем «жидкости», обладает выразительной анимацией; подходит для степени достижения цели, загрузки ресурсов и подобных метрик.

## Входные поля
### Обязательные
- `percent`: number, диапазон значений [0,1], текущий процент или прогресс.

### Опциональные
- `shape`: string, по умолчанию `circle`, допустимо `circle`/`rect`/`pin`/`triangle`.
- `style.backgroundColor`: string, цвет фона.
- `style.color`: string, цвет заполнения.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Убедитесь, что процент нормализован; один график показывает только один показатель — для нескольких метрик постройте несколько индикаторов рядом; в заголовке уместно указать, например, «Выполнение цели 85%».

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
