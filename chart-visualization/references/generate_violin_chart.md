# generate_violin_chart — скрипичная диаграмма

## Назначение
Объединяет кривую плотности распределения (ядерная оценка) со статистикой «ящика с усами» для сравнения формы распределения по категориям. Подходит для сопоставления серий экспериментов или групп наблюдений.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `category` (string) и `value` (number), опционально `group` (string).

### Опциональные
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], список цветов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.
- `axisYTitle`: string, по умолчанию пустая строка.

## Рекомендации
Размер выборки в каждой категории желательно ≥30 — иначе оценка плотности нестабильна. Если нужно подчеркнуть квартили, медиану и выбросы, дополните диаграммой «ящик с усами».

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
