# generate_pin_map — карта точек

## Назначение
Отмечает маркерами несколько POI на карте Китая; во всплывающем окне можно показать изображение или пояснение. Подходит для распределения точек продаж, размещения активов.

## Входные поля
### Обязательные
- `title`: string, обязателен, до 16 знаков, кратко описывает набор точек.
- `data`: string[], обязателен, список названий POI на территории Китая.

### Опциональные
- `markerPopup.type`: string, фиксированное значение `image`.
- `markerPopup.width`: number, по умолчанию `40`, ширина изображения.
- `markerPopup.height`: number, по умолчанию `40`, высота изображения.
- `markerPopup.borderRadius`: number, по умолчанию `8`, радиус скругления изображения.
- `width`: number, по умолчанию `1600`.
- `height`: number, по умолчанию `1000`.

## Рекомендации
Названия POI должны содержать достаточную географическую привязку (город + ориентир); при необходимости добавляйте в название атрибут, например «Магазин A, Сюйхуэй, Шанхай». Карта опирается на данные AMap и поддерживает только Китай.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
