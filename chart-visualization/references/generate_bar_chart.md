# generate_bar_chart — горизонтальная столбчатая диаграмма

## Назначение
Сравнивает показатели разных категорий или групп горизонтальными полосами. Подходит для рейтингов Top-N, сопоставления регионов или каналов.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит минимум `category` (string) и `value` (number); для группировки или наложения нужно дополнительно передать `group` (string).

### Опциональные
- `group`: boolean, по умолчанию `false`; при включении разные `group` показываются рядом друг с другом, требует `stack=false` и наличия поля `group` в данных.
- `stack`: boolean, по умолчанию `true`; при включении разные `group` накладываются в одной полосе, требует `group=false` и наличия поля `group` в данных.
- `style.backgroundColor`: string, задаёт цвет фона (например, `#fff`).
- `style.palette`: string[], список цветов серий.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`, задаёт ширину диаграммы.
- `height`: number, по умолчанию `400`, задаёт высоту диаграммы.
- `title`: string, по умолчанию пустая строка, задаёт заголовок диаграммы.
- `axisXTitle`: string, по умолчанию пустая строка, задаёт заголовок оси X.
- `axisYTitle`: string, по умолчанию пустая строка, задаёт заголовок оси Y.

## Рекомендации
Держите названия категорий короткими; при большом числе серий переходите на наложение или отбирайте только ключевые позиции, чтобы диаграмма не перегружалась.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
