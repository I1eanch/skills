# generate_scatter_chart — точечная диаграмма

## Назначение
Показывает связь между двумя непрерывными переменными; разные группы можно различать цветом или формой. Подходит для анализа корреляций и поиска кластеров.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `x` (number) и `y` (number), опционально `group` (string).

### Опциональные
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], палитра для серий.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.
- `axisYTitle`: string, по умолчанию пустая строка.

## Рекомендации
Перед построением стоит нормализовать величины с разной размерностью; при очень большом объёме данных сначала сделайте выборку; используйте `group`, чтобы обозначить категории или результаты кластеризации — так график читается легче.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
