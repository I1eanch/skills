# generate_histogram_chart — гистограмма

## Назначение
Показывает распределение частот или вероятностей непрерывной величины через разбиение на интервалы, помогает увидеть асимметрию, выбросы и области концентрации.

## Входные поля
### Обязательные
- `data`: number[], не менее 1 значения, используется для построения распределения частот.

### Опциональные
- `binNumber`: number, число интервалов; если не задано, оценивается автоматически.
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], цвета столбцов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.
- `axisYTitle`: string, по умолчанию пустая строка.

## Рекомендации
Перед передачей очистите пустые и аномальные значения; желательный объём выборки ≥30; подбирайте `binNumber` по смыслу задачи, балансируя детализацию и общую картину распределения.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
