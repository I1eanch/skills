# generate_column_chart — вертикальная столбчатая диаграмма

## Назначение
Сравнивает показатели разных категорий или периодов вертикальными столбцами, с группировкой или наложением. Обычно применяется для продаж, выручки, потока посетителей.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит минимум `category` (string) и `value` (number); для группировки или наложения нужно дополнить полем `group` (string).

### Опциональные
- `group`: boolean, по умолчанию `true`; показывает разные `group` рядом друг с другом по сериям, при включении требуется `stack=false` и наличие `group` в данных.
- `stack`: boolean, по умолчанию `false`; накладывает разные `group` в одном столбце, при включении требуется `group=false` и наличие `group` в данных.
- `style.backgroundColor`: string, задаёт цвет фона.
- `style.palette`: string[], список цветов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.
- `axisXTitle`: string, по умолчанию пустая строка.
- `axisYTitle`: string, по умолчанию пустая строка.

## Рекомендации
При большом числе категорий (>12) отбирайте Top-N или агрегируйте; в режиме наложения убедитесь, что каждая запись содержит поле `group`, иначе проверка не пройдёт.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
