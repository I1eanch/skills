# generate_fishbone_diagram — диаграмма Исикавы

## Назначение
Служит для анализа первопричин: центральная проблема размещается на основной оси, а ветви слева и справа показывают категории причин и их уточняющие узлы. Типично для управления качеством и оптимизации процессов.

## Входные поля
### Обязательные
- `data`: object, обязательное, содержит как минимум `name` корневого узла; раскрывается рекурсивно через `children` (array<object>), рекомендуемая глубина — не более 3 уровней.

### Опциональные
- `style.texture`: string, по умолчанию `default`, доступно `default`/`rough` для переключения стиля линий.
- `theme`: string, по умолчанию `default`, доступно `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.

## Рекомендации
В корневом узле формулируйте саму проблему. Ветви первого уровня называйте категориями причин (люди, оборудование, материалы, методы и т. д.). В листьях описывайте конкретные проявления, придерживаясь коротких формулировок.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
