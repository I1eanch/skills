# generate_mind_map — карта мыслей

## Назначение
Разворачивает 2–3 уровня ветвей вокруг центральной темы, помогая организовать идеи, планы или структуру знаний; часто применяется для брейнсторминга и планирования решений.

## Входные поля
### Обязательные
- `data`: object, обязательное; узел содержит минимум `name`, может рекурсивно расширяться через `children` (array<object>), рекомендуемая глубина ≤3.

### Опциональные
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.

## Рекомендации
В центральном узле указывайте тему, ветви первого уровня отражают основные измерения (цели, ресурсы, риски и т. п.), листовые узлы формулируйте короткими фразами; если ветвей слишком много, лучше разбить на несколько карт.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
