# generate_treemap_chart — древовидная карта (treemap)

## Назначение
Показывает иерархическую структуру и вес каждого узла с помощью вложенных прямоугольников. Подходит для долей активов, доли рынка, объёма каталогов и т. п.

## Входные поля
### Обязательные
- `data`: array<object>, массив узлов; каждый содержит `name` (string) и `value` (number), может рекурсивно включать `children`.

### Опциональные
- `style.backgroundColor`: string, цвет фона.
- `style.palette`: string[], список цветов палитры.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Убедитесь, что `value` каждого узла ≥ 0 и совпадает с суммой значений дочерних узлов; не делайте иерархию слишком глубокой — при необходимости агрегируйте заранее; для лучшей читаемости добавляйте единицы измерения в имена узлов.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
