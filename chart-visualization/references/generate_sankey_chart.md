# generate_sankey_chart — диаграмма Сэнки

## Назначение
Показывает направление и объём потоков ресурсов, энергии или пользователей между узлами. Подходит для распределения бюджета, путей трафика, структуры энергопотребления.

## Входные поля
### Обязательные
- `data`: array<object>, каждая запись содержит `source` (string), `target` (string) и `value` (number).

### Опциональные
- `nodeAlign`: string, по умолчанию `center`, допустимо `left`/`right`/`justify`/`center`.
- `style.backgroundColor`: string, задаёт цвет фона.
- `style.palette`: string[], цвета узлов.
- `style.texture`: string, по умолчанию `default`, допустимо `default`/`rough`.
- `theme`: string, по умолчанию `default`, допустимо `default`/`academy`/`dark`.
- `width`: number, по умолчанию `600`.
- `height`: number, по умолчанию `400`.
- `title`: string, по умолчанию пустая строка.

## Рекомендации
Имена узлов должны быть уникальными; избегайте избыточных пересечений. Циклы предварительно разворачивайте в последовательность этапов; малые потоки можно отфильтровать по порогу, чтобы подчеркнуть главное.

## Результат

Спецификация данных для локального рендера: график строится средствами `visual-explainer`, `recharts` или `ckm-slides` (Chart.js). Внешний сервис рендеринга в этой установке не используется.
